# tg-scribe — Telegram для AI-агентов на Mac

[English](README.md) | Русский

Локальный MCP-сервер для macOS дает AI-агенту, например Claude Code, доступ к вашему аккаунту Telegram. Агент выгружает переписку в Markdown-файлы на диске и работает с ними: ищет, анализирует, пересказывает, готовит ответы.

Сервер работает на вашем Mac и подключается к Telegram от вашего имени через официальный протокол MTProto. Для подключения используется библиотека Telethon и ваш собственный `api_id`. Распознавание текста на фото работает на Apple Vision, поэтому нужен Mac.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `list_dialogs` | Показывает 50 последних чатов. Остальные находит поиском по названию |
| `sync_chat` | Выгружает переписку в архив: за нужное число дней или целиком. При следующих вызовах догружает новые сообщения |
| `transcribe` | Расшифровывает голосовые и кружки. Нужен Telegram Premium |
| `ocr_photos` | Распознает текст на фото через Apple Vision, прямо на Mac |
| `fetch_media` | Скачивает фото, чтобы агент посмотрел на него сам |
| `describe_photo` | Сохраняет в архив короткое описание фото |
| `send_message` | Отправляет сообщение после вашего подтверждения |

### Как это выглядит

1. Вы спрашиваете: «О чем договорились в чате с прорабом за последние три недели?»
2. Агент вызывает `sync_chat` с `days=21`. Сервер выгружает в архив три недели переписки, от новых сообщений к старым.
3. Агент ищет по архиву нужные сообщения. Важное голосовое помечено «не расшифровано» — агент расшифровывает его через `transcribe`. На фото сметы нужны цифры — агент распознает текст через `ocr_photos`.
4. Агент отвечает и ссылается на id сообщений.
5. На следующий день вы спрашиваете: «Что нового?» `sync_chat` догружает только новые сообщения. Голосовые и фото в них сервер обрабатывает сразу, до 20 штук за вызов.
6. Вы спрашиваете: «А что решили в прошлом месяце?» Агент вызывает `sync_chat` с `days=60`, и сервер догружает недостающую старую историю.

Голосовые и фото из старой истории сервер не обрабатывает при выгрузке. Агент расшифровывает и распознает их, только когда они нужны для задачи. Поэтому выгрузка занимает минуты, а не часы, и не тратит лимиты.

## Архив

Переписка лежит в папке `archive/` рядом с исходным кодом MCP, по одному файлу на месяц. Папка внесена в `.gitignore`.

```
archive/Иван-Петров__123456789/2026-10.md
```

Одна строка — одно сообщение. Пример файла:

```
[2026-10-31 14:02] #48213 Иван Петров: Скинул смету
[2026-10-31 14:03] #48214 Иван Петров [фото, с текстом]: 
  [на фото] Плитка: 48 000 ₽
  [на фото] Итого: 120 000 ₽
[2026-10-31 14:05] #48215 Я ↩48213: [голосовое 0:42] «Дорого, давай обсудим вечером»
[2026-10-31 14:06] #48216 Иван Петров [фото: план кухни с размерами]: вот план
[2026-10-31 14:07] #48217 Иван Петров [переслано из «Ремонт без боли»]: Цены на плитку
  с ноября выросли на 15%
[2026-10-31 14:10] #48218 Иван Петров: [кружок 0:35, не расшифровано]
```

Что означают элементы строки:

| Элемент | Значение |
|---|---|
| `[2026-10-31 14:02]` | Дата и время по часовому поясу вашего Mac |
| `#48213` | id сообщения |
| `Я` | Вы |
| `↩48213` | Ответ на сообщение 48213 |
| Строка с отступом в 2 пробела | Продолжение многострочного сообщения |
| `[переслано из «…»]` | Пересланное сообщение и его источник |
| `[голосовое 0:42] «…»`, `[кружок 0:35] «…»` | Расшифровка голосового или кружка |
| `[голосовое 1:10, не расшифровано]` | Голосовое еще не расшифровано |
| `[фото]` | Фото еще не обработано |
| `[фото, с текстом]` | На фото есть текст, он в строках `[на фото]` ниже |
| `[фото, без текста]` | На фото нет текста |
| `[фото: …]` | Описание фото, которое сохранил агент |
| `[фото, недоступно]` | Фото удалено из Telegram |
| `[фото, не читается]` | Файл фото поврежден |
| `[файл report.pdf]`, `[видео]`, `[стикер 👍]`, `[gif]`, `[опрос]`, `[геопозиция]`, `[контакт]` | Другие вложения |

Архив только пополняется: изменения и удаления сообщений в Telegram в него не попадают.

## Что понадобится

- Mac.
- [uv](https://docs.astral.sh/uv/) — он сам поставит Python 3.12 и зависимости.
- AI-агент с поддержкой MCP, например [Claude Code](https://claude.com/claude-code).
- Аккаунт Telegram. Для расшифровки голосовых нужен Telegram Premium.

## Установка

### 1. Скачайте проект и поставьте зависимости

```bash
git clone https://github.com/rodion1010/tg-scribe.git tg-scribe
cd tg-scribe
uv sync
```

### 2. Получите api_id и api_hash

Telegram пускает сторонние программы в аккаунт только через зарегистрированное приложение. Регистрация бесплатная и занимает пару минут.

1. Откройте [my.telegram.org](https://my.telegram.org) и введите номер телефона в международном формате, например `+79991234567`.
2. Введите на сайте код подтверждения. Он придет в Telegram от аккаунта «Telegram», а не по СМС.
3. Выберите **API development tools**.
4. Заполните поля:
   - **App title** — любое название без слова «Telegram», например `tgc`. Слово «Telegram» в названии запрещают правила API.
   - **Short name** — от 5 до 32 латинских букв и цифр, например `tgclaude`.
   - **URL** — оставьте пустым.
   - **Platform** — Desktop.
   - **Description** — оставьте пустым.
5. Нажмите **Create application**. На странице появятся **App api_id** — число и **App api_hash** — строка из 32 символов.

Если сайт показывает `ERROR`, откройте его в другом браузере. На один аккаунт можно создать одно приложение: если оно уже есть, сайт сразу покажет его данные.

Никому не показывайте api_hash и не коммитьте его: с ним можно выдавать себя за ваше приложение.

### 3. Сохраните api_id и api_hash в конфиг

Создайте папку и файл конфига:

```bash
mkdir -p ~/.tgc && chmod 700 ~/.tgc
nano ~/.tgc/config.toml
```

Вставьте в файл свои значения:

```toml
api_id = 12345678
api_hash = "0123456789abcdef0123456789abcdef"
```

Закройте доступ к файлу для других пользователей:

```bash
chmod 600 ~/.tgc/config.toml
```

### 4. Войдите в аккаунт

```bash
uv run python -m tgc.login
```

Программа спросит номер телефона, код из Telegram и облачный пароль, если включена двухэтапная проверка. После входа появится файл `~/.tgc/tgc.session`.

Этот файл дает полный доступ к вашему аккаунту без кода и пароля. Не копируйте его, не публикуйте и не кладите в облако. Если файл утек, завершите сеанс в Telegram: **Настройки → Устройства**.

### 5. Подключите сервер к агенту

Сервер запускается командой:

```bash
uv run --directory /путь/к/tg-scribe python -m tgc.server
```

Здесь `/путь/к/tg-scribe` — папка, куда вы скачали проект. Добавьте эту команду в настройки MCP-серверов вашего агента. Ниже описано подключение к Claude Code.

В проекте уже есть `.mcp.json` с этим сервером. Запустите Claude Code в папке проекта и разрешите сервер `tg`, когда Claude Code спросит.

Чтобы Telegram был доступен из любой папки, подключите сервер для своего пользователя:

```bash
claude mcp add tg --scope user -- uv run --directory /путь/к/tg-scribe python -m tgc.server
```

Архив и в этом случае лежит в `archive/` рядом с исходным кодом MCP.

Правило подтверждения отправки из `.claude/settings.json` проекта в других папках не действует. Добавьте его в `~/.claude/settings.json`:

```json
{
  "permissions": {
    "ask": ["mcp__tg__send_message"]
  }
}
```

### 6. Проверьте подключение

Спросите агента: «Покажи мои последние чаты в Telegram». Он вызовет `list_dialogs` и покажет список.

## Разрешения

Агент отправляет сообщение только после вашего подтверждения. В Claude Code это обеспечивает файл `.claude/settings.json`: он разрешает читать чаты, выгружать их и распознавать медиа без вопросов, а на отправку ставит правило `ask`. Claude Code каждый раз показывает текст и чат и ждет вашего «да». Не переносите `send_message` в `allow`.

Правило действует только в папке проекта. Для других папок добавьте его в `~/.claude/settings.json`, как описано в шаге 5. В других агентах настройте подтверждение для `send_message` так же.

## Как указать чат

Чат можно назвать по части названия, но поиск Telegram находит не все чаты, и агент может выбрать похожий. Перед отправкой надежнее указать id чата: его показывает `list_dialogs`. После отправки сервер называет чат, куда ушло сообщение.

Чтобы видеть id прямо в Telegram, включите его показ в отладочном меню. В Telegram Desktop откройте **Настройки → Продвинутые настройки → Экспериментальные настройки** и включите **Show Peer IDs in Profile**. Как открыть отладочное меню на других платформах, описано в [инструкции tginfo](https://tginfo.me/open-debug-menu/).

Меняйте в отладочном меню только эту настройку: другие пункты могут сломать приложение или удалить секретные чаты.

## Ограничения и риски

- **Лимиты Telegram.** Если Telegram просит подождать дольше 30 секунд, сервер останавливается и сообщает, сколько ждать. Дольше 30 секунд он сам не ждет, чтобы не упасть по таймауту.
- **Большие выгрузки** идут за несколько вызовов: каждый работает до 200 секунд. 150 тысяч сообщений загрузятся примерно за 10 вызовов, агент повторяет их сам.
- **Одна сессия за раз.** Если две сессии агента обращаются к Telegram одновременно, вторая получит ответ «Telegram занят» и повторит позже.
- **Правила Telegram.** [Условия API](https://core.telegram.org/api/terms) запрещают мешать исчезновению самоуничтожающихся сообщений, а сервер сохраняет в архив сообщения из чатов с автоудалением. [Условия лицензирования контента](https://telegram.org/tos/content-licensing) запрещают обучать модели ИИ на данных Telegram. В архиве есть и чужие сообщения, поэтому запретите провайдеру агента обучать модели на ваших данных. В claude.ai это настройка **Help improve Claude**.
- **Текст из чатов — данные, а не команды.** Сервер просит агента не выполнять просьбы из переписки. Подтверждайте отправку, только когда прочитали текст.

## Разработка

Запустите тесты:

```bash
uv run pytest
```

Код разделен на четыре модуля:

- `tgc/client.py` — подключение к Telegram и поиск чата;
- `tgc/archive.py` — формат архива, синхронизация, расшифровка и распознавание;
- `tgc/server.py` — MCP-инструменты и инструкции для агента;
- `tgc/login.py` — вход в аккаунт.
